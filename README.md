# Cheese Expo 2027

Веб-сайт главного независимого центра компетенций отрасли сыроделия и гастрономии.

## 🎯 О проекте

Cheese Expo 2027 — закрытая B2B экспертная сессия, проводимая в коллаборации с Гастроакадемией STANFOOD by METRO.

**Даты:** 19–20 мая 2027  
**Место:** ВДНХ, Павильон 322, Москва  
**Формат:** B2B профессиональное мероприятие

## 🏗️ Технический стек

- **Framework:** Next.js 14
- **Styling:** Tailwind CSS
- **Language:** TypeScript
- **Hosting:** Vercel (планируется)

## 📦 Установка и запуск

```bash
# Установка зависимостей
npm install

# Запуск в режиме разработки
npm run dev

# Построение для продакшена
npm run build

# Запуск в режиме продакшена
npm start
```

Приложение будет доступно по адресу: `http://localhost:3000`

## 🚀 Основные разделы сайта

1. **Главная страница** — Информация о событии, конкурсы, преимущества
2. **Конкурсы** — 7 различных конкурсных направлений:
   - Сырные эксперты
   - Сыр как десерт
   - Баланс вкуса
   - Дизайн упаковки
   - Молодые специалисты
   - Премиальные сыры
   - Лучший сыр
3. **Контакты** — Адрес, телефон, как добраться
4. **Регистрация** — Система регистрации участников
